# Audio cues (ACE-Step)

Drop an `.mp3` here with one of these names and the game uses it instead of the built-in synthesized placeholder.
No code change is needed. Loops must loop seamlessly.

| File | Use | Loop |
|---|---|---|
| theme.mp3 | Show intro sting (~4 s) | no |
| lobby.mp3 | Title screen bed | yes |
| bedEasy.mp3 / bedMedium.mp3 / bedHard.mp3 | Question beds per tier, rising tension | yes |
| suspense.mp3 | After lock-in, before reveal (heartbeat/drumroll) | yes |
| phoneBed.mp3 | Phone a Friend ticking bed | yes |
| lock.mp3 | Answer locked | no |
| correct.mp3 / wrong.mp3 | Reveal stings | no |
| miss.mp3 | Double Chance first miss | no |
| lifeline.mp3 | Any lifeline used | no |
| walk.mp3 | Walk away | no |
| win.mp3 | Jackpot fanfare | no |
| tick.mp3 | Last-10-seconds tick | no |
| applause.mp3 / cheer.mp3 / gasp.mp3 / murmur.mp3 | Crowd (better as SFX than generated music) | murmur only |

Check ACE-Step's license and output terms before public use.
